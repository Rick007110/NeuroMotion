# Security

NeuroMotion opens files people send each other (`.nmproj` projects and endorphin
scenes, characters and poses), so a file that crashes the app, hangs it or makes it
write somewhere unexpected is a security problem.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub:
**Security → Report a vulnerability** on the repository
([direct link](https://github.com/Rick007110/NeuroMotion/security/advisories/new)).

Include the version or commit, your operating system, the steps or file that trigger
it, and what happens. You'll get an answer within a week. Once it's fixed we'll credit
you in the release notes, unless you'd rather stay anonymous.

## Supported versions

NeuroMotion is in early development; only the latest release and `main` get fixes.
